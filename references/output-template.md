# 固定输出模板

完整解析必须只使用以下五个二级标题，名称、顺序和数量不得改变。内部可按题号或内容使用三级标题；不要新增其他二级标题。

```markdown
## 题目解析

### 题意与条件

- 只重建影响求解的原题条件。
- 仅在关键内容模糊、遮挡、矛盾或存在多种读法时说明识别边界。

### 分析过程

1. 按原题编号或选项建立对应关系。
2. 给出必要的依据、推导、方程式或计算。
3. 完成适合该题型的闭环核验。
4. 用独立重算、代回、反例、守恒、边界或替代路径完成至少一种可见的关键核验。
5. 信息不足时明确条件化结论，不虚构确定答案。

## 答案

- （1）……
- （2）……

选择题可写为：

**答案：A、C。**

需要抄写的方程式、结构简式、数值和单位在此完整重现，不只写“见上”。“答案”必须与三轮复核后的最终结论一致，不得复制尚未复核的候选答案。若关键题面尚不确定，写明答案成立条件或说明暂不能唯一确定。

## 知识点

1. **知识点名称**：本题实际使用的定义、规律或判据及其适用条件。
2. **知识点名称**：与本题推理的直接联系。

## 易错点分析

1. **易错点**：与本题推理直接相关的常见错误。
   - **原因**：错误产生的具体原因。
   - **纠正**：可操作的判断或检查方法。

## 教师辅助教学建议

1. **教学目标**：本题应落实的核心能力。
2. **课堂追问**：给出 2～4 个有梯度的问题。
3. **教学活动或板书**：提供可直接执行的安排。
4. **变式训练**：改变一个关键条件，并说明训练目的。
5. **评价建议**：指出过程性评分点或诊断方法。
```

## 按题型组织“题目解析”

- **选择题**：明确题干问法，逐项写“判断—依据—结论”，最后用排除项复查、反例或答案个数核验唯一性。
- **填空/简答题**：按原空号或小问编号，写出规范、可评分的关键词和必要理由。
- **计算题**：展示核心关系、代入、单位、有效数字，并至少用代回、守恒、数量级或另一关系式核验结果。
- **实验题**：按题目实际涉及的“目的—原理—装置/操作—现象—结论—误差/安全”组织，不机械补齐未设问内容。
- **图表题**：先说明坐标、单位、图例、特殊点、趋势和控制变量，再解释结论。
- **推断/流程题**：区分证据、假设和确定结论，用后续信息验证并排查替代路径。
- **有机/结构题**：明确结构连接、反应位点、限制条件、对称性及计数或极值边界。

## 非完整解析场景

以下情况不套用五段模板，只发送完成下一步所必需的简短信息：

1. 图片含多道独立题而用户未指定目标：列出题号或位置并询问解析哪一道。
2. 无法可靠判断题目边界或目标区域：请求用户指出区域。
3. 关键题面无法辨认且不能给出有意义的条件化结论：指出需补拍的具体区域。

## 特殊情况

- **用户要求多道题**：仍只使用一套五段标题；在各部分内部按题号分组，确保解析与答案一一对应。
- **用户要求批改手写解答**：先独立求解并完成三轮复核，再在“易错点分析”中对照手写过程；不得先采信其结论。
- **题面矛盾或答案不唯一**：依次写明“按题面字面条件”“按常见命题意图”“需补充的条件”。
- **用户只给知识点**：仍使用五段标题；“题目解析”用于概念机制与典型情境，“答案”给出标准结论。
