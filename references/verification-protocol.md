# 三轮独立复核协议

本协议是完整答案输出前的强制质量门禁。首次求解只产生“候选答案”，不得直接发送给用户。三轮复核必须改变检查视角，不能只是重复阅读同一推导。

## 第一轮：题意与证据复核

目的：确认求解的是原题，而不是误读、漏读或被批注影响后的题目。

逐项检查：

1. 题干任务词、否定词、数量词、极值词和条件词是否识别正确。
2. 数值、单位、物质、结构连接、图例、坐标、反应条件和小问编号是否完整。
3. 是否把后加手写答案、圈选、草稿或透印误当作题设。
4. 每一个结论是否能追溯到清晰题面或明确规律；题面不清处是否会改变答案。
5. 选择题是否所有影响答案唯一性的选项都能可靠辨认。

本轮失败时，重新识别题意；关键条件仍不确定则给条件化结论或请求补图，不进入确定答案。

## 第二轮：独立重算与交叉验证

目的：避免首次思路中的运算、配平、枚举或逻辑错误。

1. 暂时不沿用首次推导的中间结果，从原始条件重新求解。
2. 可行时换用第二种独立方法，例如：
   - 守恒法与关系式法互证；
   - 正向推导与答案代回互证；
   - 代数计算与数量级/极限估算互证；
   - 逐项判断与反例检验互证；
   - 正向推断与特征现象回代互证；
   - 枚举计数与分类总数/对称性检查互证。
3. 第二种方法确实不可用时，至少从原始条件重新推导一次，并逐步核对中间量、单位、符号和边界；不得直接复制首次推导。对纯概念题，可改用定义逐词核对、反例检验或适用条件审查。
4. 方程式单独检查反应能否发生，再检查物质、原子、电荷、电子、系数、介质、条件和箭头。

两次结果不一致时，不得选择“看起来更合理”的答案；必须定位分歧来源，修正后重新执行本轮。

## 第三轮：反证与输出一致性复核

目的：主动尝试推翻候选答案，并检查解析与最终答案是否一致。

1. 假设候选答案错误，寻找反例、遗漏情况、替代路径、边界条件或题面限定。
2. 检查常见方向性错误：正确/不正确、增大/减小、阳极/阴极、氧化/还原、少量/过量、吸热/放热、充分/恰好等。
3. 按题型完成终检：
   - **选择题**：答案个数符合题型；每个入选项成立，每个排除项都有充分理由。
   - **填空/简答题**：每一空均有答案，关键词可评分，问原因不只写现象，问操作不只写目的。
   - **计算题**：结果代回成立，单位和有效数字正确，数量级合理，无漏乘、漏除或基准量混淆。
   - **实验题**：操作、现象和结论因果一致；装置连接、气密性、除杂顺序、误差方向和安全性无矛盾。
   - **图表题**：结论对应正确坐标区间、单位、图例和控制变量，没有把相关性写成题目未支持的因果性。
   - **推断/流程题**：所有中间物质或步骤能同时满足前后证据，不存在未排除的合理替代方案。
   - **有机/结构题**：碳骨架、官能团、价键、条件和计数分类无遗漏、无重复；极值构型确实可同时实现。
4. 对照“题目解析”和“答案”：编号、选项、数值、单位、方程式、正负号及条件完全一致。
5. 最后检查 LaTeX 渲染和化学语义；格式正确不能替代化学正确。

本轮发现新问题时，返回相应步骤修正，并重新完成受影响的后续复核。

## 放行规则

只有满足以下条件才可输出无条件确定答案：

- 三轮复核均完成；
- 独立求解结果收敛；
- 不存在未解释的矛盾；
- 关键题面足够清晰；
- 解析与答案完全一致。

若多轮检查后仍无法收敛，必须如实说明不确定点、已有结论及需要补充的信息，不得为了给出答案而虚构确定性。复核过程默认不逐条展示给用户，也不声称“保证绝对正确”；只在“题目解析”中保留支撑最终答案所需的关键核验。三轮复核用于显著降低错误率，不能把模型自检表述成绝对保证。
